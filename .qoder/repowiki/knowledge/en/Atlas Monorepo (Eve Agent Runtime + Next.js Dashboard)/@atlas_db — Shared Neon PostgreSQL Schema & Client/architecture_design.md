Single-package library (`@atlas/db`) with two entry points: `src/index.ts` exports both a singleton `db` instance created at module load time and a `createDb()` factory that reads `DATABASE_URL` from `@atlas/env/server`, connects via `@neondatabase/serverless`, and wraps it with `drizzle-orm/neon-http`. The schema is split by domain under `src/schema/` (`auth.ts` for user/session/account/verification, `booking.ts` for orders) and re-exported through a barrel `src/schema/index.ts`; each table is declared with `pgTable` plus a sibling `relations()` definition so joins are fully typed. Migrations live under `src/migrations/` and are generated/applied by Drizzle Kit configured in `drizzle.config.ts`, which loads `DATABASE_URL` from `../../apps/web/.env`. The package has no query logic of its own — consumers import `db` or call `createDb()` to obtain a fully typed Drizzle instance against Neon's serverless driver.
