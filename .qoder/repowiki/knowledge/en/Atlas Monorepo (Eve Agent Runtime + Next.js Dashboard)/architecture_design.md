The root declares Bun workspaces under `apps/*` and `packages/*` and delegates all cross-package orchestration to Turborepo: `build`, `lint`, `check-types`, and `dev` tasks are defined with `dependsOn: ["^task"]` so dependency order is enforced transitively across the workspace. A single `globalEnv` list in `turbo.json` centralizes every secret (database, S3, Telegram, Better Auth, AI gateway) so both the Eve runtime and the web app consume the same environment surface without per-package duplication. Cross-cutting concerns live in sibling packages consumed by apps: `@atlas/db` defines the Drizzle schema used by `packages_auth` and `packages_api`; `packages_api` exposes tRPC procedures mounted by the web frontend; `packages_ui` provides React components reused by the Next.js app; `packages_atlas` wraps the external flight booking API called from backend code. All packages extend the shared base TypeScript config from `@atlas/config` so type checking is centralized, and lint/format rules are uniformly applied via Ultracite presets configured at the repo root.
