Built on Next.js App Router with route groups: `(protected)` holds authenticated pages (activity, bookings, integrations, trips) guarded by an async `ProtectedLayout` that calls `@atlas/auth` to fetch a session and redirects unauthenticated users to `/auth`; `(public)/auth` hosts the login page. The root `src/app/layout.tsx` injects global fonts and wraps children in `Providers`, which composes `next-themes` `ThemeProvider`, TanStack React Query's `QueryClientProvider`, and Sonner's `Toaster`. Server-side API boundaries are exposed under `src/app/api/`: `/api/trpc/[trpc]` is a tRPC fetch adapter wired to `@atlas/api/routers/index` via a shared `createContext`, and `/api/auth/[...all]` delegates all auth flows to Better-Auth via `toNextJsHandler`. Client-side state uses a singleton `queryClient` and a typed tRPC proxy (`utils/trpc.ts`) configured with `httpBatchLink` and `credentials: 'include'` for cookie-based sessions. A rewrite in `next.config.ts` proxies `/api/eve/*` to an external runtime URL from `@atlas/env/server`. UI primitives, sidebar, header, and dashboard chrome live in `src/components`, while cross-cutting client hooks (e.g., `use-assistant-panel`) live in `src/hooks`.
