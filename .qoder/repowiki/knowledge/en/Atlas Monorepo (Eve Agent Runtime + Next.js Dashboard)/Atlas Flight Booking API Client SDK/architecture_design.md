The package is a server-only SDK (`type: module`, `main` and `exports` point directly at `src/index.ts`) built around a thin `AtlasClient` class in `src/client.ts` that centralizes HTTP POST calls with `Accept`/`Content-Type` headers plus `x-atlas-client-id` / `x-atlas-client-secret` authentication. The public entry `src/index.ts` exports a `createAtlasClient()` factory that reads `ATLAS_API_URL`, `ATLAS_CLIENT_ID`, `ATLAS_CLIENT_SECRET` from `@atlas/env/server` and composes a namespaced object tree: `flights.*` (search, verify, seat/baggage, order lifecycle, offer pricing, smart/price-compare search), `postBooking.*` (PNR extract/claim, refunds, void, ancillaries, order list/regenerate, stop-ticket-issuance), `utility.*` (atrip token, balance, email query, route export), and `webhook` (incident listing, URL registration). Each feature lives in its own subdirectory under `src/` with one endpoint per file; every endpoint exposes a `createXxx(client)` factory returning an object whose methods delegate to `client.post<T>(path, body)`. Request/response shapes are declared as local TypeScript `interface`s co-located with their handler. Feature directories expose a barrel `index.ts` re-exporting all factories, which the root index wires into the top-level client namespace. There is no shared DTO layer beyond `AtlasClientConfig`.
