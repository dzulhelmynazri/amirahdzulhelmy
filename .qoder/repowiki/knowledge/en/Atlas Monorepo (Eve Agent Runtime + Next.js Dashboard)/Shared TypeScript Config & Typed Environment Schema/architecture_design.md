Two sibling packages under `packages/` form the module. `@atlas/config` is a private, zero-dependency package whose sole purpose is to publish `tsconfig.base.json`, a strict TypeScript compiler options baseline (ESNext target/module, bundler resolution, strict mode, isolatedModules, noUncheckedIndexedAccess) consumed by other workspace packages through `workspace:*`. `@atlas/env` exposes two entry points — `./server` and `./web` — each exporting a single `env` object created with `@t3-oss/env-core` (Node) or `@t3-oss/env-nextjs` (browser). The server entry loads `.env` via `dotenv/config` and validates all server-side secrets and URLs with Zod schemas; the web entry only whitelists `NEXT_PUBLIC_*` variables for the browser. Both entries share the same validation strategy: `emptyStringAsUndefined: true`, optional `SKIP_ENV_VALIDATION` bypass, and per-field Zod validators (e.g. `z.url()`, `z.string().min(1)`). Dependency direction is one-way: `@atlas/env` depends on `@atlas/config` as a dev dependency for shared TS settings, while `@atlas/config` has no dependencies.
