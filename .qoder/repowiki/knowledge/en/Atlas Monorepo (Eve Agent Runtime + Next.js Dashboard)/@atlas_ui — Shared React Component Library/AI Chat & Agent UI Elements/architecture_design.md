Flat collection of single-file React components under `packages/ui/src/components/ai-elements/`, each exporting a cohesive set of related sub-components (e.g. `message.tsx` exports `Message`, `MessageContent`, `MessageActions`, `MessageResponse`, `MessageBranch*`). Components are client-side (`"use client"`) and compose the shared `@atlas/ui` primitives (`Button`, `Card`, `Accordion`, `Select`, `Tooltip`, etc.) plus `lucide-react` icons. Cross-cutting concerns are isolated in dedicated files: `code-block.tsx` provides an async Shiki-based syntax highlighter with per-language highlighter caching, token caching, subscriber callbacks for progressive rendering, and a `CodeBlockContext` consumed by `CodeBlockCopyButton`; `conversation.tsx` wraps `use-stick-to-bottom` to implement scroll-to-bottom chat behavior; `node.tsx` and `panel.tsx` wrap `@xyflow/react` to add graph-node styling and handles. Inter-component communication inside a file uses React Context (e.g. `MessageBranchContext`, `CodeBlockContext`) rather than props drilling, and stateful groups expose typed prop interfaces alongside their component functions. External data types come from `ai` package (`UIMessage`, `Tool`) and `streamdown` for rich message rendering.
