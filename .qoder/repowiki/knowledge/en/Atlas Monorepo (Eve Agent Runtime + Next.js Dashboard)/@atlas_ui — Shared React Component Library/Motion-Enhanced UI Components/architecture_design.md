The module is split into two layers. `components/motion/` holds presentation components that wrap native elements in `motion/react` primitives (`motion.button`, `motion.div`, `motion.svg`) and compose them via composition — e.g. `button/stateful.tsx` and `button/magnetic.tsx` extend the base `Button` from `button/base.tsx`, while `MorphPopover` composes `MorphPopoverTrigger` and `MorphPopoverContent` through a local `MorphContext`. Cross-cutting concerns live in `lib/`: `ease.ts` centralizes all spring and cubic-bezier easing tokens (`SPRING_PRESS`, `SPRING_SWAP`, `SPRING_PANEL`, `EASE_OUT`, etc.) consumed by every component; `utils.ts` provides the `cn` class merger; `text-shimmer.ts` exports keyframes and styles for shimmer effects; `hooks/` contains reusable hooks like `use-hover-capable`. Scroll-driven behavior is provided by `smooth-scroll.tsx`, which wraps content in a `SmoothScroll` provider backed by Lenis (with a reduced-motion fallback to native scroll listeners) and exposes `scrollY`, `progress`, `velocity` as MotionValues via `useSmoothScroll`; `scroll-progress.tsx` consumes this context to render bar or circle indicators. Popover positioning is isolated in `popover-position.ts` using a `ResizeObserver` + layout measurement hook so `popover-morph.tsx` can compute portal placement without tight coupling.
