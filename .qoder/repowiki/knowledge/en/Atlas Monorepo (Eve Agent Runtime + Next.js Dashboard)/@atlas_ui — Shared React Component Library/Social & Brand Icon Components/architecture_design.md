Flat collection of one-file-per-brand React functional components under `packages/ui/src/components/socials/`, each exporting a named component that renders an inline `<svg>` element typed with React's `SVGProps<SVGSVGElement>`. A single `index.ts` barrel file re-exports every icon via `export * from "./<brand>"`, so consumers import all icons from one path without knowing individual filenames. There is no shared base component or registry — each icon is self-contained and independent, with no cross-imports between files.
