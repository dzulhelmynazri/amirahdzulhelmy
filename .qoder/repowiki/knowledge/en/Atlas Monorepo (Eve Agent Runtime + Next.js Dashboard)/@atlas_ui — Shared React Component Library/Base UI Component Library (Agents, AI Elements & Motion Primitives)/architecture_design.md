The module is organized into four thematic sub-packages under `src/components/`:

- Flat primitive components (e.g. `button.tsx`, `dialog.tsx`, `input.tsx`) that wrap `@base-ui/react` primitives with `class-variance-authority` variants and Tailwind utility classes via `cn()` from `@atlas/ui/lib/utils`.
- `agents/` — a cohesive chat/message system centered on `message.tsx`, which composes `MessageBubble`, `MessageScroller`, `MessageGroup`, `MessageAvatar`, `MessageContent`, etc., and exposes a `MessageContext` / `MessageSideContext` for side-aware styling; subfolders (`agent-activity`, `approval-card`, `loading-states`) add activity rows, approval cards, and shimmer loading states.
- `ai-elements/` — higher-order compositional components for AI workflows (`conversation`, `agent`, `artifact`, `tool`, `plan`, `sandbox`, `terminal`, `web-preview`, etc.) that orchestrate primitives like Button, Dialog, Tabs, and external libraries such as `use-stick-to-bottom`, `framer-motion`, and `lucide-react` icons.
- `motion/` — motion-enhanced variants of form controls and UX widgets (`magnetic`, `action-swap`, `popover-morph`, `smooth-scroll`, `text-shimmer`, `scroll-progress`) using `motion/react`; includes a nested `button/` sub-package splitting base, magnetic, and stateful button behaviors.
- `socials/` — icon/logo components for third-party services (Gmail, Slack, Notion, Telegram, WhatsApp, Google suite) re-exported through `index.ts`. Dependency direction is one-way: `ai-elements` and `agents` consume primitives from the flat root and each other; `motion` and `socials` are leaf utilities consumed by both. All components are client components (`"use client"`) where interactivity or browser APIs are needed.
