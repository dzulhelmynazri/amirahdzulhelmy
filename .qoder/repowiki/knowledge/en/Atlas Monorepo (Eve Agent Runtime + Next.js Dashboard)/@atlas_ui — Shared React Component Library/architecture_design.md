The package is organized as a flat `src/components/` tree split into four thematic sub-libraries — base components (agents, ai-elements, motion, socials) — all re-exported through explicit `exports` mappings in `package.json` so consumers import via stable paths like `@atlas/ui/components/agents/*`, `@atlas/ui/components/motion/button`, and `@atlas/ui/components/socials`. All children share a common design system built on Base UI + Tailwind CSS with shadcn configuration (`components.json`) that aliases `@atlas/ui/components`, `@atlas/ui/lib/utils`, and `@atlas/ui/hooks` for consistent imports. Cross-cutting concerns live in `src/lib/` (utils, easing, favicon, text-shimmer) and `src/styles/globals.css`, which the whole package ships as `@atlas/ui/globals.css`. The agents and ai-elements layers compose each other (ai-elements build on top of the shared design system while agents render conversation-level flows), and motion primitives provide reusable spring/easing tokens used by both base and agent components.
