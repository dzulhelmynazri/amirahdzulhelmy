The module is a flat collection of React Server/Client components under `packages/ui/src/components/agents/`, each file exporting one or more composable primitives. A few sub-folders group related pieces: `agent-activity/` (activity rows with types), `approval-card/` (approval card variants), and `loading-states/` (progress/thinking shimmer). Cross-cutting shared primitives live at the top level — `message.tsx` defines the `Message`/`MessageGroup`/`MessageAvatar`/`MessageContent`/`MessageHeader`/`MessageFooter`/`MessageMarker`/`MessageTyping` composition and re-exports bubble/scroller components from sibling files; `message-bubble.tsx` provides varianted bubble surfaces (`solid|soft|tint|outline|ghost|danger`) with collapsible support; `streaming-response.tsx` wraps streamed content with copy/retry/feedback actions and a sources disclosure; `tool-approval.tsx` renders pending/approved/denied tool execution cards with parameter details; `citations.tsx` exposes `Citation`, `CitationList`, `CitationStack`, and `Citations` with favicon support; `agent-disclosure.tsx` is a transform-only reveal primitive reused by StreamingResponse, ToolApproval, and Citations; `message-context.tsx` supplies side alignment via React context; `prompt-input.tsx`, `code-block.tsx`, `file-diff.tsx`, `image-generation.tsx`, `todo-list.tsx`, `tool-result.tsx`, `agent-code.tsx` are specialized display widgets. Dependency direction is strictly inward toward shared primitives (`agent-disclosure`, `message-context`, `lib/ease`, `lib/utils`, `lib/favicon`) and outward only to icon libraries (`lucide-react`) and motion primitives (`motion/react`). All components are marked `'use client'` because they rely on `motion/react`, `useState`, `useId`, and browser APIs like clipboard.
