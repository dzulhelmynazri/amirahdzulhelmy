The runtime is an Eve v0.33 application rooted at `agent/agent.ts`, which declares the agent via `defineAgent` with compaction tuned for large booking payloads, token-cost guardrails, and a session-scoped model resolver that switches between a primary model (`zai/glm-5.2`) and a cheaper `EVE_TASK_MODEL` for schedule/subagent events. Channel adapters live under `agent/channels/` as single-file factories (`eveChannel`, `telegramChannel`, `twilioChannel`, `resendChannel`) exporting configured channel instances. Authentication is centralized in `agent/lib/auth.ts` implementing Eve's `AuthFn<Request>` by calling `@atlas/auth`'s `auth.api.getSession` and mapping it to Eve's `{ attributes, authenticator, issuer, principalId, principalType }` shape, composed with `vercelOidc` and `localDev`. User-scoped external integrations are created lazily inside tool factories by reading `ctx.session.auth.current.principalId` and constructing a new `Composio` session per user, exposed through `agent/tools/composio.ts`. Domain workflows are split into subagents under `agent/subagents/booking` and `agent/subagents/support`, each with its own `agent.ts`, `instructions.md`, and `tools/` folder of domain-specific tools; reusable single-purpose tools live directly under `agent/tools/`. Background work runs via `agent/schedules/` (disruption monitoring, price watching). The package uses ESM with path imports (`#*` → `./agent/*`, `#evals/*` → `./evals/*`) so consumers reference agent code via `#agent/...`. Evaluation suites under `evals/atlas/` exercise agent behavior without side effects.
