Single-file module (`src/index.ts`) that composes a `files-sdk` client via `createFiles`, wiring an S3 adapter (configured from `@atlas/env/server` env vars: bucket, credentials, endpoint, region) and stacking six plugins in a fixed order: signed URL policy, in-memory cache for head/url/download operations, file size validation, content-type detection, gzip/deflate compression, and AES encryption using a base64-encoded key. The module exposes both a factory `createStorage()` and a pre-instantiated singleton `storage`, consumed by other packages through the `@atlas/storage` package entry defined in `package.json`. Dependencies are strictly inward: this package depends on `files-sdk`, `@aws-sdk/*`, and `@atlas/env`; it has no internal sub-packages or additional layers.
