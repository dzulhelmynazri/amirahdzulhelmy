The package is a self-contained tRPC server rooted at `src/index.ts`, which creates a shared `initTRPC` instance with a strongly-typed `Context` (from `src/context.ts`) and exports reusable `publicProcedure` and `protectedProcedure` builders. Context is resolved per request by calling `@atlas/auth`'s `auth.api.getSession` against a `NextRequest`, attaching an optional session to every procedure. Feature scopes are split into small routers under `src/routers/` (`health.ts`, `user.ts`, `booking.ts`) and mounted together in `src/routers/index.ts` as `appRouter`, which also re-exports the inferred `AppRouter` type for end-to-end type safety. The `lib/` directory is reserved for shared helpers but is currently empty. Dependencies flow inward: routers depend only on the shared `t`/procedures from `../index`, never directly on `@trpc/server`, keeping router code framework-agnostic beyond the procedure primitives. Routers access domain data via `@atlas/db` (Drizzle ORM) and environment variables via `@atlas/env`.
