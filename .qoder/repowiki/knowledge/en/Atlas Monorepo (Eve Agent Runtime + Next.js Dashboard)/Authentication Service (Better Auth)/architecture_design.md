Single-entry module that exports `createAuth` (factory) and a default `auth` singleton from `src/index.ts`. It composes the Better Auth framework using the Drizzle adapter (`drizzleAdapter`) against a shared `@atlas/db` connection and schema (`@atlas/db/schema/auth`), enabling email/password, Google social provider, and a Telegram bot plugin. Configuration is sourced exclusively from `@atlas/env/server` (`BETTER_AUTH_URL`, `TELEGRAM_BOT_TOKEN`, `GOOGLE_*`, `CORS_ORIGIN`, `BETTER_AUTH_SECRET`). The package exposes both a default export and wildcard subpath exports via its `exports` field so consumers can import either the factory or individual source files directly.
